# Aesthetic Wines Admin

This repository is separate from the Aesthetic Wines public website.
Use pnpm with the committed lockfile and Node.js version in `.nvmrc`.
Run `pnpm build`, `pnpm format:check`, and relevant inherited tests before pushing.
Keep the upstream MIT license and attribution intact.
Do not hand-edit `src/routeTree.gen.ts`; the router plugin generates it.
Template authentication and mock data are examples, not production integrations.
Do not rewrite published Git history.
